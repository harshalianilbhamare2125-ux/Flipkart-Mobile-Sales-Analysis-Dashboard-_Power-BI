# 📱 Flipkart Mobile Sales Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing Flipkart mobile data using **Python and Power BI**. The goal is to clean, analyze, and visualize mobile product data to identify useful insights related to price, ratings, brands, models, memory, and storage.

## 🛠️ Tools & Technologies

- 🐍 Python
- 📊 Pandas
- 🔢 NumPy
- 📈 Matplotlib
- 📊 Seaborn
- ⚡ Power BI
- 📁 CSV Dataset

## 🔍 Python Data Analysis

Python was used for:

- Data loading and exploration
- Data cleaning
- Handling missing values
- Data transformation
- Exploratory Data Analysis (EDA)
- Price and rating analysis
- Brand, memory, and storage analysis
- Creating visualizations
